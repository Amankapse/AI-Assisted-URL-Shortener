## Intentionally Untested Or Lower-Coverage Areas

- DTO/entity accessor boilerplate has lower value as direct unit-test target.
- The Spring Boot application entrypoint has minimal direct coverage.
- Production infrastructure behavior such as managed database failover, external secret manager integration, and centralized observability is documented but not implemented in the prototype.
- k6 performance scripts were not executed locally because k6 is not installed.
- No mutation testing or SAST/SCA plugin is configured.

## Remaining Gaps

- Branch coverage could improve around global exception fallbacks and uncommon configuration branches.
- End-to-end CI execution must be confirmed on GitHub after the branch is pushed.
- A future build-agent configuration should address Mockito's dynamic-agent warning before newer JDKs disallow dynamic agent loading by default.
